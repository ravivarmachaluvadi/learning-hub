Website copy

This is Code Viewer's website copy. Reading, Practice, Hint, Compare, Visual, Next, Done / Revise, the file filter and Search in code work here, and UI pages (.html) run with their tests. Your progress, drafts and attempts are kept in this browser only. Java, Python and JavaScript cannot run here: ▶ Run shows how to run the file on a PC (copy it into an IntelliJ scratch file, or java File.java). Save, new files, Push, the ticks and Java suggestions need Code Viewer on the laptop.

Shortcuts

Ctrl+BHide / show the file list
Ctrl+PFind a file by name
↑ / ↓ in the file listPrevious / next file, which opens as you go (hold the key and only the one it stops on opens). → / ← open and close a folder, Enter does too
Ctrl+Shift+FSearch inside every file
Ctrl+EnterRun what is in the editor: Java (compiled first), Python, JavaScript (with Node.js). On a UI page (.html): its test block. Lines that say what they expected get ✓ or ✗
Python and JavaScript filesRun, Practice (function bodies hidden, Hints, timer, Done), Try, Compare and Next work as for Java. A syntax error is underlined in red; every file and line in a traceback or stack is a link. A .py can import a module beside it. Suggestions, parameter hints and hover as you type: JavaScript's from the editor, Python's from Jedi (when it is installed: pip install jedi)
UI pages (.html)The page shows beside the code as a browser shows it, redrawn as you type; ↻ Reload under it starts it fresh, Preview hides it. Console under it lists every line it logs as you click, errors linked to their line, also after Ctrl+Enter; alert() shows there as [alert] … instead of a box. Suggestions as you type: tags and attributes in the markup, real JavaScript ones in every <script> (the page's own functions too), and CSS properties in <style>, with only the values that property accepts. Ctrl+Enter runs its <script type="test"> block once the page has loaded (await works there) and ticks each check line; browsers skip that block, so it never runs on its own. Practice hides the page's JavaScript function bodies; the markup and CSS stay. The page runs locked away from Code Viewer: alert() and confirm() only log, a loop that runs 2 s without a break is stopped, and other files beside it (a .css, a .js) do not load

Edits stay a draft in this browser (orange dot in the tree) until you Save. A Try copy is kept the same way until you Discard it, and Save never writes it; there is one at a time, so starting Try on another file deletes the older copy. Practice attempts, their timer and the hints you opened are kept the same way, never in the file: the Attempts tab lists them and clears several at once. Clearing this browser's site data loses them. Done / Revise marks, solve times and reviews are saved on this PC in tools\codeview-state.json.

Showing the solution, or Compare, before an attempt is solved marks the file ↻ revise (the bar that says so has Undo). A pass after that does not count as solved until you Reset and solve it fresh.

Java autocomplete, parameter hints, Javadoc on hover and red underlines for javac's errors work while you edit (Edit, Try, Scratch pad). In practice mode they are off, as in most interview editors; ⋯ → Autocomplete in Practice turns them on. They come from your JDK's own compiler, running in the background; the first suggestion after a start takes a few seconds.

A file marked done comes back for review (◷ in the list) after 3 days, then 7, 21 and 60 days each time you solve it again in practice mode.
